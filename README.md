# Cloud and DevOps – Git & GitHub

## Experiment 4: Implementation of Version Control Operations using Git & GitHub

### Course
BCSE0808 – Cloud and DevOps Lab

## Aim

To install and configure Git, perform local version control operations such as
`init`, `add`, and `commit`, connect a local repository to a remote GitHub
repository, and push/update code using Git commands.

## Tools Used

- Git
- GitHub
- Vim / Text Editor
- Ubuntu Terminal

## Operations Performed

1. Verified Git installation using `git --version`
2. Created a project directory using `mkdir`
3. Initialized a local Git repository using `git init`
4. Created and tracked `README.md`
5. Checked repository status using `git status`
6. Staged files using `git add`
7. Created commits using `git commit`
8. Created a remote repository on GitHub
9. Connected the local repository to GitHub using `git remote add`
10. Renamed the default branch to `main`
11. Pushed the project to GitHub using `git push`
12. Created and edited `exp.sh`
13. Committed subsequent changes
14. Pushed updated changes to GitHub
15. Verified the repository using `git status` and `git log`

## Commit History

The project contains three major commits:

- **First Commit** – Added `README.md`
- **Second Commit** – Added `exp.sh`
- **updated exp.sh** – Updated the shell script

## Result

A local Git repository was successfully created and connected to GitHub.
Files were tracked and committed across multiple revisions, and all changes
were successfully pushed to the remote GitHub repository.

## Learning Outcomes

- Understood the working directory, staging area, and repository in Git.
- Learned to initialize a repository and track files.
- Learned to create and manage commits.
- Connected a local repository to a remote GitHub repository.
- Practiced editing files and committing incremental changes.
- Learned to verify repository state using `git status` and `git log`.
